# 2.0.0-ko.2-tile.1

CrossPoint Reader KO **2.0.0-ko.2** 위에 타일 테마와 내장 명조 글꼴을 얹은 개인 포크 빌드입니다.
Xteink X3에 맞춰 만들었고, X3에서만 사용해 봤습니다 (X4는 같은 이미지로 부팅되지만 확인하지 않았습니다).
공식 CrossPoint / CrossPoint KO 릴리스가 아닙니다.

## KO 2.0.0-ko.2 와 다른 점

- **타일 테마** (기본 테마): 순정 펌웨어 느낌의 홈 화면. 책 카드 하나(표지, 제목, 진행률, 읽은 시간)와
  2x2 타일(읽기로 돌아가기 / 폴더 / 설정 / 파일 전송), 글자만 있는 버튼 안내.
  뒤로가기는 최근 읽은 책 목록을 띄웁니다.
- **내장 리더 글꼴: 부크크 명조 17pt** (KS X 1001 한글 2,350자 + 한자 4,620자, 무압축).
  SD 카드 글꼴 없이 바로 읽을 수 있습니다.
- **특수문자 내장**: 그리스 문자, 악센트 알파벳, 원문자, 도형, ♥★, 전각 문장부호, 가나, 선 문자
  1,237자를 압축 글꼴로 내장했습니다. 이 글자들 때문에 SD 글꼴을 고를 필요가 없습니다.
- **보조 글꼴** (설정 → 리더): 내장 글꼴에 없는 글자(KS X 1001 밖의 한글, 드문 한자)만 SD 글꼴에서
  가져옵니다. 평소에는 "없음"으로 두세요. 켜면 느려집니다.
- UI 글꼴 Pretendard 11pt, 홈 제목 Pretendard Bold 14pt.
- X3: 절전 화면 이미지가 4단계 회색을 고르게 쓰도록 임계값을 바꿨고, EPUB 이미지 페이지의
  회색이 얼룩지던 것을 고쳤습니다.
- **업데이트 확인**은 이 포크의 릴리스를 봅니다 (KO 공식 릴리스로 덮어쓰지 않습니다).

## 설치

`crosspoint-2.0.0-ko.2-tile.1-x3-x4.bin` 을 SD 카드에 복사한 뒤
설정 → 시스템 → SD 카드 펌웨어 업데이트에서 고릅니다. (CrossPoint KO가 이미 설치된 기기 기준)

- 다른 테마를 쓰다가 올렸다면 설정 → 테마에서 **타일**을 고르세요.
- 펌웨어 크기 6.19 MB로, 순정 OTA 파티션(6.25 MB) 안에 들어갑니다.
